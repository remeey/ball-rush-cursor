# Ball Rush Cursor

A stylized arrow pointer with layered cyan and violet edging, a subtle neon glow, and a small sparkle.

## Windows downloads

- [Download the Windows ZIP](https://raw.githubusercontent.com/remeey/ball-rush-cursor/main/BallRushPointer.zip)
- [Download the Windows cursor file](https://raw.githubusercontent.com/remeey/ball-rush-cursor/main/BallRushPointer.cur)

### Install on Windows

1. Download and extract `BallRushPointer.zip`.
2. Open **Settings → Bluetooth & devices → Mouse → Additional mouse settings**.
3. Open the **Pointers** tab. Under **Customize**, select **Normal Select**, then choose **Browse**.
4. Select `BallRushPointer.cur` and click **Apply**.

## Mac artwork

- [Download the Mac PNG](https://raw.githubusercontent.com/remeey/ball-rush-cursor/main/BallRushPointer-Mac.png) — transparent, 64 × 64 pixels, designed for a 32-point pointer at 2× scale.
- [View the scalable SVG](https://github.com/remeey/ball-rush-cursor/blob/main/BallRushPointer-Mac.svg)

macOS includes settings to adjust pointer size and color, but it does not provide a built-in way to replace the system arrow with arbitrary artwork. For a custom system cursor, you can try a third-party utility such as [Mousecape](https://github.com/alexzielenski/Mousecape). Mousecape relies on macOS internals, so compatibility can vary by macOS version.

### Use the PNG with Mousecape

1. Install and open Mousecape from its [official GitHub releases](https://github.com/alexzielenski/Mousecape/releases).
2. In Mousecape, press **Command-N** to make a cape, then **Command-E** to edit it.
3. Add a cursor, choose the arrow/normal pointer type, and drag `BallRushPointer-Mac.png` into its image area.
4. Set the cursor size to **32 × 32 points** and the hotspot to **3 × 2 points** (the arrow tip).
5. Save the cape, then apply it in Mousecape.

Mousecape is third-party software and may need its own helper tool. If you only want a built-in Mac adjustment, open **System Settings → Accessibility → Display → Pointer** and change the pointer size or outline/fill colors.

The PNG and SVG are artwork files; they do not install a system cursor by themselves.
