# Ball Rush Cursor

A stylized 48-pixel Windows arrow with layered cyan and violet edging, a subtle neon glow, and a small sparkle.

## Downloads

- [Download the ZIP](https://raw.githubusercontent.com/remeey/ball-rush-cursor/main/BallRushPointer.zip)
- [Download the cursor file](https://raw.githubusercontent.com/remeey/ball-rush-cursor/main/BallRushPointer.cur)

## Install on Windows

1. Download and extract `BallRushPointer.zip`.
2. Open **Settings → Bluetooth & devices → Mouse → Additional mouse settings**.
3. Open the **Pointers** tab. Under **Customize**, select **Normal Select**, then choose **Browse**.
4. Select `BallRushPointer.cur` and click **Apply**.

To use it on another Windows computer, copy the `.cur` file there and repeat these steps. This replaces the regular arrow pointer; text and resize pointers remain unchanged.
